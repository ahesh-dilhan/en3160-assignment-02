# Supplied assignment inputs

These nine images were supplied in `a2images.zip` with the EN3160 assignment.
They are included unchanged so the experiments can be reproduced directly from
a clone. Their original authorship/licensing is not specified in the archive;
no new ownership or blanket license is asserted for these supplied materials.

- `the_berry_farms_sunflower_field.jpeg`: Q1 input, read at quarter resolution.
- `flag.png`, `wadham.jpg`: provided Q3 example pair.
- `pcbs/AECC1.jpg`: Q4 reference template.
- `pcbs/AAAA1.jpg`, `ADAD1.jpg`, `AECC2.jpg`, `AECC3.jpg`, `AECC4.jpg`: Q4 targets.

`scripts/prepare_data.ps1` verifies the original archive SHA-256 and checks the
extracted file contents against it. New Q3 image pairs have separate attribution
in `assets/q3/ATTRIBUTION.md`.
